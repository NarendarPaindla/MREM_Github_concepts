## 📘 One-Day Workshop on *“Mastering GitHub with OOPs Mini Project: Employee Leave Management System”*

### **Total Duration:** 6 Hours

### **Mode:** Practical + Hands-on

---

### **🕐 Session 1: Introduction to Git & GitHub (1 Hour)**

**Topics Covered:**

1. What is Version Control System (VCS)?
2. Difference between Git and GitHub
3. Installing Git and configuring username/email
4. Creating a GitHub Account
5. Creating a New Repository
6. Understanding basic Git Commands:

   * `git init`
   * `git add`
   * `git commit`
   * `git status`
   * `git log`
7. Pushing local project to GitHub (`git push`)
8. Pulling updates from GitHub (`git pull`)
9. Adding README.md and .gitignore files

**Hands-On:**

* Students create and push their first repository to GitHub.

---

### **🕐 Session 2: OOPs Concept & Mini Project – Employee Leave Management System (1 Hour)**

**Topics Covered:**

1. Quick Recap of OOPs Concept (Focus on **Encapsulation**)
2. Designing Mini Project: *Employee Leave Management System*

   * Create `Employee` class with private attributes
   * Implement getter and setter methods
   * Add functions for applying leave and showing details
3. Run the project and test output
4. Initialize Git in project folder
5. Commit and push code to GitHub repository

**Outcome:**
Students upload a working project demonstrating OOPs concept using encapsulation.

---

### **🕐 Session 3: GitHub Branching, Collaboration & Workflow (2 Hours)**

**Topics Covered:**

1. **Branching and Merging**

   * Creating and switching branches (`git branch`, `git checkout`)
   * Merging branches (`git merge`)
   * Resolving merge conflicts

2. **Collaboration on GitHub**

   * Forking repositories
   * Pull Requests (PR) and Code Review process
   * Assigning issues and managing contributors

3. **Understanding GitHub Interface**

   * Overview of tabs: Code, Issues, Pull Requests, Projects, Wiki
   * Using Issues for tracking bugs/features
   * Managing collaborators and permissions

4. **Team Activity (Hands-On):**

   * Students form pairs
   * One creates repo → others fork → make PRs → merge changes

**Outcome:**
Students learn complete collaboration workflow on GitHub.

---

### **🕐 Session 4: Advanced GitHub Features, Automation & Wrap-Up (2 Hours)**

**Topics Covered:**

1. **GitHub Desktop & GUI Tools**

   * Using GitHub Desktop for easy commits and sync

2. **GitHub Pages (Optional)**

   * Hosting a simple web page or documentation site from a repo

3. **GitHub Actions (Overview)**

   * What are workflows and CI/CD
   * Automating testing or deployment (basic introduction)

4. **Repository Management**

   * Protecting branches and setting rules
   * Viewing commit history and contributors graph
   * Cloning and contributing to open-source projects

5. **Wrap-Up**

   * Recap of Git + GitHub workflow
   * How to use GitHub for portfolio and projects
   * Q&A and student feedback

**Hands-On:**

* Enable GitHub Pages for README demo or documentation.
* Explore Actions templates and automation samples.

---

### **✅ Final Deliverables**

By the end of the workshop, each student will have:

* A complete **GitHub repository** with multiple commits and branches
* A working **OOPs Mini Project – Employee Leave Management System**
* Experience in **collaborating, forking, merging, and managing GitHub repositories**
